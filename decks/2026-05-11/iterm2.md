# iTerm2

> A modern terminal replacement for macOS

- Free and open source (GPL-2.0)
- Drop-in replacement for Apple's Terminal.app
- Actively maintained since 2010
- Default terminal of choice for many macOS developers

---

## Why developers love it

- **Split panes** — horizontal/vertical splits in a single window
- **Search** — full-buffer regex search with Cmd+F
- **Hotkey window** — global shortcut drops down a terminal anywhere
- **Shell integration** — mark prompts, jump between commands, upload/download
- **tmux integration** — native windows for tmux sessions
- **Profiles, triggers, autocomplete** — deep customization out of the box
